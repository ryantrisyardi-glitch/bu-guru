# Aplikasi Perpisahan (Android, gratis)
1. Edit bagian CONFIG di www/index.html (nama, pesan, daftar foto/video/musik).
2. Taruh file media di www/media/ (foto .jpg, video .mp4, musik .mp3). Disarankan foto < 500 KB, video 720p.
3. Buat repo di github.com, upload semua isi folder ini (jadi satu).
4. Buka tab Actions > Build APK > tunggu ±5 menit > unduh "aplikasi-apk" di bagian Artifacts.
5. Kirim app-debug.apk ke orang tua murid (WhatsApp/Drive), lalu instal.
Tes cepat di HP/PC tanpa build: buka www/index.html di browser.
